# Midnight Curio Shop · 심야 골동품점

이상한 물건의 진짜 가치와 취급법을 밝혀내고, 흥정으로 나만의 골동품점을 키우는 Roblox 게임 프로젝트입니다.

**현재 단계: 기획. 실행 가능한 게임 코드는 아직 없습니다.**

## 게임 콘셉트

물건 접수 → 관찰·감정 → 근거를 들어 흥정 → 보관·야간 관찰 → 판매 또는 전시 → 가게 확장.

물건에 남은 각인과 수선 흔적으로 가치를 추정하고, 밤에 드러나는 이상 현상으로 취급법을 알아냅니다. 매입한 물건을 팔지, 더 조사할지, 가게에 남길지 선택합니다.

## 첫 시제품 목표

- 물건 하나를 회전하고 단서를 발견하기
- 발견한 근거로 매입 가격 협상하기
- 매입·판매 결과를 잔액과 재고에 반영하기
- 야간 이상 현상 하나 구현하기
- PC·모바일에서 전체 흐름 확인하기

## 개발 환경 계획

- Roblox Studio / Luau
- Git으로 코드와 문서 관리
- Studio와 외부 파일 연결 방식은 구현 시작 시 확정

설치·실행 방법과 플레이 영상은 실제 구현 후 추가합니다.

## 참고 작품

[No Umbrellas Allowed](https://store.steampowered.com/app/1301390/No_Umbrellas_Allowed/)의 감정·흥정·상점 운영 구조를 참고합니다. 본 프로젝트의 세계관, 캐릭터, 아이템과 표현은 독자적으로 설계합니다. 해당 작품과 제휴한 프로젝트가 아닙니다.

## 공개 범위

개발 과정과 기획·구현 판단을 포트폴리오로 기록하는 공개 저장소입니다. 문서에는 향후 게임의 단서와 시스템에 대한 스포일러가 포함될 수 있습니다.

별도 라이선스는 아직 부여하지 않았습니다. 공개 열람과 재사용 허가는 구분됩니다.
